# 01-数学基础

深度学习的基础数学知识学习资源

## 学习顺序
1. 线性代数（最重要）
2. 微积分
3. 概率统计
4. 离散数学

## 学习时间建议
- 线性代数：2-3 周
- 微积分：1-2 周（复习为主）
- 概率统计：1-2 周
- 离散数学：1 周
