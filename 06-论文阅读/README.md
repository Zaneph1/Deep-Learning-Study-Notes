## 论文阅读方法

1. **三遍阅读法**
   - 第一遍：标题、摘要、结论、图表
   - 第二遍：方法、实验、结果
   - 第三遍：推导、证明、细节

2. **做笔记**
   - 问题背景
   - 核心创新点
   - 方法概述
   - 实验结果
   - 个人思考

3. **定期复习**
   - 每周回顾一次
   - 建立知识图谱
